# Folder Names Inside `recipes-*` in Yocto

The folder names inside `recipes-*` are **not fixed or strictly enforced** by Yocto, but following convention keeps things organized.

## Do you need a `recipes-core` folder?

**No, it is not strictly required.** BitBake does not care what you name the subfolders inside your layer.

BitBake locates recipes using the pattern configured in your `meta-mylayer/conf/layer.conf`:

```bitbake
BBFILES += "${LAYERDIR}/recipes-*/*/*.bb \
            ${LAYERDIR}/recipes-*/*/*.bbappend"
```

Because of the wildcard `recipes-*/*/*.bb`, BitBake will scan **any folder** that starts with `recipes-` and pick up `.bb` or `.bbappend` files located inside its subdirectories.

---

## Yocto Naming Conventions

While BitBake doesn't enforce standard folder names, the Yocto Project uses standard prefixes by convention to categorize software:

| Folder Name | Typical Contents |
| --- | --- |
| **`recipes-core`** | System images (`.bb` / `.bbappend`), init scripts, base system configs, `packagegroup-core-*`. |
| **`recipes-example`** | Boilerplate / default templates generated by `bitbake-layers create-layer`. |
| **`recipes-support`** | Libraries, utilities, or background daemons. |
| **`recipes-bsp`** | Bootloaders (U-Boot), device tree overlays, kernel configurations. |
| **`recipes-extended`** | Higher-level tools, networking software, or larger applications. |

---

## Best Practice for Your Custom Image

You have two choices:

1. **Create `recipes-core/images/` (Recommended):**

   ```bash
   mkdir -p recipes-core/images
   ```

   Placing image recipes (like `my-custom-image.bb` or `core-image-minimal.bbappend`) inside `recipes-core/images/` makes your layer clean and familiar to any Yocto developer.

2. **Use `recipes-example/`:**

   You can place image recipes right inside `recipes-example/images/` if you want. BitBake will find and parse them just fine, though it looks less conventional.
